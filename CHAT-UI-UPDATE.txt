CHAT INTERFACE UPDATE

This update changes the existing private conversation screen to use a full-viewport, mobile-first layout. It preserves the existing chat API, message rendering, voice-note recording, attachment upload, and LiveKit call controls.

Deployment: deploy the complete project root as usual. No new database migration or environment variable is introduced by this chat layout change.
